## Before sending anything

1. **The museum is not deployed yet.** Both letters are worded as "built", which
   is true. Do not upgrade that to "live" or offer a public link until it ships.
   A private preview link is the right offer in the meantime.
2. **Verify contacts.** No email addresses are asserted in these drafts, because
   I could not verify any. The routes to try are listed in each file.
3. **Check the numbers.** The proposal cites 50 accessions, ~250 images, 94
   holdings assets, 302 MB. Confirm against the live data before circulating.

## A note on tone

Both letters lead with what is already built rather than what we hope to do,
because that is the only real leverage here: these are people who receive
speculative approaches constantly. The thing that makes ours different is that
the museum exists, the rights posture is genuinely strict, and the gap we are
pointing at — no kinetic record of any African martial art, anywhere — is real
and checkable.

Neither letter asks for a dataset in the first message. The UMONS letter asks a
licensing question about data we are already using and openly credit. The HKMALA
letter asks for a conversation and explicitly declines to ask for the archive.
That ordering is deliberate; please keep it if you edit.
