# Tela Template Design Brief

The standard is Canva and Adobe Express **surpassed**: each template must look like a working art director made it for a real client — a specific grid, a deliberate type pairing, one strong idea, copy that reads like a publication, and a motif that belongs to the movement. Nothing generic. Nothing that could be produced by swapping colours on a neighbour.

This brief is for anyone (human or agent) writing designs under `services/tela/designs/`.

## 1. The engine you draw with

Everything is a `TelaVectorObject` (see `types.ts`, interface `TelaVectorObject`). Use the kit — never build objects by hand:

```ts
import { rect, ellipse, circle, line, hr, vr, path, text, below, right, image, imageSlot, columns, span, scale, frame, folio, dropCap, mix, alpha, isDark } from '../../templateKit';
import { copy } from '../../copy';
import * as orn from '../../ornaments';
```

- `text(x, y, w, value, { size, font, weight, color, align, tracking, leading, italic, transform, wrap, label, role })` — `font` is a **FontKey** from `services/tela/telaFonts.ts` (`'playfair'`, `'inter'`, `'bebas'`…). Text **wraps to `w` by default** and computes its own height, so stack with `below(obj, gap)`. Tracking is a fraction of size (`.12` = 12 %). Leading is a multiple (1.05 headline, 1.35–1.5 body).
- `rect(x,y,w,h,fill,{rx, stroke, strokeWidth, opacity, rotation, gradient, shadow, blend, blur, dash, label, role})`.
- `path(x,y,w,h, d, fill, {...})` scales a path authored in a 0..100 box. Combine with `orn.*` generators (`sunburstPath`, `zigzagPath`, `wavePath`, `archPath`, `pointedArchPath`, `ogeeArchPath`, `quatrefoilPath`, `lotusPath`, `whiplashPath`, `leafPath`, `fanPath`, `scallopPath`, `stepPyramidPath`, `chevronPath`, `blobPath`, `boomerangPath`, `balloonPath`, `burstPath`, `tornEdgePath`, `brushStrokePath`, `bracketPath`, `cScrollPath`, `starPath`, `eightStarPath`, `polygonPath`).
- Object generators return arrays — spread them: `...orn.dotField(...)`, `orn.stripes`, `orn.radialLines`, `orn.rings`, `orn.checker`, `orn.starTessellation`, `orn.mosaic`, `orn.perspectiveGrid`, `orn.confetti`, `orn.frameCorners`, `orn.frieze`, `orn.specks`.
- `imageSlot(x,y,w,h,{tone:'light'|'dark', rx, rotation, caption, frame, frameWidth, shade, silent})` draws a quiet photo well the way a comp does (tonal field + small caps hint). Use it wherever a photo/illustration belongs. Never draw grey boxes with "ADD IMAGE" in them.
- `image(x,y,w,h, url, srcW, srcH)` only for public-domain plates (Met Open Access CC0 URLs) **and always with an `imageSlot` behind it** so a failed load still reads as designed. Credit the work in a caption.
- `frame(W,H,margin)` gives `fr.x fr.y fr.w fr.h fr.right fr.bottom fr.cx fr.cy`. `columns(fr.x, fr.w, n, gutter)` and `span(cols, a, b)` for grids. `folio(fr, left, right, color)` for running feet. `dropCap(...)` for openers.
- Colours: `mix(hex, ±amount)` tints/shades, `alpha(hex, a)`, `isDark(hex)`.
- Copy: `copy.headline(voice, i)`, `.deck`, `.body`, `.paragraphs(voice, n)`, `.caption`, `.quote`, `.byline`, `.kicker`. Voices: editorial, culture, science, travel, music, fashion, community, faith, business, kids, photo, comic, food, event, education, personal. Write your own copy when the movement calls for a specific voice (a manifesto, a broadside, a psalm) — but it must read as real.

## 2. Hard rules (the lint enforces most)

1. **First object = full-page ground** `rect(0,0,W,H, paper, {role:'GROUND'})`.
2. **No text off the page.** Every TEXT box fully inside 0..W × 0..H. Ornaments may bleed.
3. **No placeholder language**: no "lorem", "replace this", "your story", "add image", "editable text", "dialogue goes here".
4. **Fonts by FontKey only.** Two to three families per template, chosen for the era (see §4). Never system-ui/Georgia raw stacks.
5. **10–220 objects per page.** Pattern fields count — keep dot fields and mosaics under ~120 objects.
6. **Two pages per era**: page 1 = opener/cover (the poster moment), page 2 = interior (body text in columns with running heads and a folio — a page someone could actually write in).
7. **Distinct geometry.** No two templates may share a layout. Every era gets its own grid, its own margins, its own type scale. Palette swaps are rejected by lint.
8. **Legibility.** Body 10.5–13 px, captions 8.5–10 px, headline ≥ 40 px on page 1. Contrast ≥ 4.5:1 for body; pick ink with `isDark(ground)`.
9. **Label everything** (`label:`) in the language of a layout program: "Masthead", "Deck", "Column 1 body", "Pull quote", "Folio", "Sunburst motif". Give `role` where meaningful (HEADLINE, DECK, BODY, CAPTION, LABEL, FOLIO, IMAGE_SLOT, ORNAMENT, RULE, GROUND).
10. **Determinism.** Use `ctx.seed` with `orn.rng` — never `Math.random`.

Verify with (from repo root):
```
npx tsx scripts/telaGallery.ts "%TEMP%/eras-<group>.html" eras <id1>,<id2>,…
```
It must print `lint clean`. Open the HTML to look at your pages; look at them the way a creative director would.

## 3. What "designed" means here

- **One idea per template.** Constructivism is the diagonal. Swiss is the modular grid with a single red mark. Gothic is verticality and light through tracery. Say the idea in the first second of looking.
- **Hierarchy you can feel with your eyes closed**: kicker → headline → deck → body → caption. Sizes from a scale (`scale(11, 1.333)`), not eyeballed.
- **Real margins.** Big enough to hold the page. Renaissance margins are unequal (inner small, outer large, bottom largest). Swiss margins are systematic. Punk margins are wrong on purpose.
- **Type is the ornament** in most modern movements. In historic ones, ornament is structural (borders, arches, initials) — draw it with `path` and the generators, and keep it *editable*: separate objects, sensible labels.
- **Texture through repetition**, not noise: friezes, dot fields, rules. Sparse is fine; empty is not.
- **Page 2 must be usable**: 2–3 text columns at 10.5–12 px with real leading, a running head, a folio, a subhead or pull quote, one image slot. This is where the template earns its keep.
- Where a movement is a **living culture** (Islamic geometry, Mughal, Ukiyo-e, Harlem Renaissance, Mexican modern, Indigenous contemporary, Afrofuturism), design from *principles* (geometry, composition, rhythm, typography) — never sacred symbols, regalia, or motifs that belong to a specific community. Indigenous contemporary is a context-first editorial frame with explicit slots for community name, language and protocol notes.

## 4. Per-era direction (style eras)

Format: **id** — grid / type (FontKeys) / motif / page 1 / page 2. Palettes are in `telaStyleEraLibrary.ts`; refine via `OVERRIDES` if a colour is wrong for the era.

### Group ancientMedieval
- **classical** — Inscriptional. Centred axis, 3 columns on p2. Type: `cinzel` caps (headline, tracked .18), `marcellus` text, `tenor` labels. Motif: meander/key border via `orn.frieze` with a square-wave path you write; laurel leaves via `leafPath` pairs; a horizontal entablature of three rules. P1: a stone "stele" — tall centred title in caps with letter-spaced date line, a single laurel pair, engraved rules. P2: two justified-feeling columns, roman-numeral folio, small-cap running head.
- **egyptian-revival** — Frontal, monumental, symmetrical. Type: `staatliches` or `bigShoulders` for display, `josefin` text (light, tracked). Motif: `lotusPath` frieze, a sun disc with wings suggested by two `fanPath` flanks, `stepPyramidPath`, vertical "column" bands with `orn.stripes`. Palette: navy ground, gold, terracotta. P1: dark ground, gold sun disc top centre, title in a horizontal cartouche (rounded rect, rx large), papyrus-rhythm rules. P2: two columns framed by two pylon-like side bands.
- **roman-mosaic** — The page as a tessellated floor. Type: `cardo` headline, `crimson` text, `marcellus` labels. Motif: `orn.mosaic` in bands and a guilloche-like border via `wavePath` pairs; central "emblema" image slot. P1: border of tesserae around a central panel; title inside a plain field (mosaics frame, they don't shout). P2: 2 columns with a mosaic band foot.
- **byzantine** — Luminous gold field, centred hierarchy. Type: `cinzel` (headline), `ebGaramond` text, `marcellus`. Motif: halo rings (`orn.rings`), a golden ground with subtle dot-field shimmer (`dotField` small, gold on gold), `archPath` arcade at head. P1: deep purple/gold, central icon-like image slot in a round-arched frame, title beneath in gold caps. P2: gold-tinted paper, single wide column + narrow marginal column for notes (like a lectionary).
- **insular** — Knotwork and the decorated initial. Type: `uncial` display (Uncial Antiqua), `alegreya` text, `almendra` labels. Motif: interlace suggested with `orn.sineOpenPath` pairs offset (two interwoven waves stroked), spiral rings, red-dot outlines (`dotField` tiny dots around the initial — the "rubrication"). P1: giant decorated initial (a 260px letter with a knotwork band behind), text begins beside it (use `dropCap` at large scale). P2: single column text with a knotwork left margin and ruled lines (faint) like a scriptorium page.
- **gothic** — Verticality and tracery light. Type: `unifraktur` (masthead only), `cardo` text, `almendra` small labels. Motif: `pointedArchPath` windows in a row, `quatrefoilPath` and `trefoilPath` tracery, vertical rules like piers, "stained glass" panes as saturated rects at low opacity inside arches. P1: near-black ground, three tall pointed windows with jewel panes, blackletter masthead across the bottom third, tiny red rubric line. P2: paper ground, two narrow columns separated by a pier rule, arches as running head.
- **renaissance** — Van de Graaf canon. Margins inner 1/9, top 1/9, outer 2/9, bottom 2/9 of the page (compute from W,H). Type: `ebGaramond` text, `cormorant` display (italic for deck), `cardo` labels. Motif: a perspective grid receding to a vanishing point (`orn.perspectiveGrid` at low opacity) on p1; golden-ratio rectangles drawn as hairlines. P1: title block on the golden section, perspective floor beneath, an image slot as an "altarpiece". P2: text block exactly on the canon, marginal glosses in the outer margin, folio at bottom outer corner.
- **baroque** — Diagonal, chiaroscuro, abundance. Type: `bodoni` italic display, `libreBaskerville` text, `cormorant`. Motif: `cScrollPath` pairs mirrored (rotation 0 / 180), a radial gradient "light" (rect with RADIAL gradient from warm gold to near black), a diagonal band. P1: black ground, gold light bursting from upper left (radial gradient ellipse), italic title set on a diagonal (rotation −8), heavy scroll ornaments at corners. P2: cream ground, two columns with a dramatic drop cap and an ornate rule.
- **rococo** — Asymmetric, airy, shell curves, pastel. Type: `cormorant` light italic display, `ebGaramond` text, `greatVibes` for one flourish word. Motif: `cScrollPath` in mint/gold, `scallopPath` edging, small `leafPath` sprays, a pale pink ground. P1: title low-left, a large asymmetric C-scroll cluster top-right, script subtitle. P2: single wide column offset left, scalloped head band, gilt hairline frame.
- **neoclassical** — Severe axis, medallion, civic. Type: `bodoni` (didone caps, tracked), `libreBaskerville` text, `cinzel` small caps. Motif: a medallion (circle with inner ring and a star), Greek-key rule via frieze, fasces-like vertical bars. P1: white/cream, centred medallion above a widely tracked title, three thin rules, all symmetric. P2: 2 columns with a medallion folio and small-cap subheads.

### Group counterculture
- **dada** — Anti-order collage. Type: `specialElite`, `archivoBlack`, `playfair`, `spaceMono` all together (this is the point), several rotations. P1: words scattered but composed (contrast of sizes, one dominant word), fragments; still legible. P2: text block set straight, but the head and folio are collaged fragments.
- **psychedelic** — Liquid, vibrating. Type: `shrikhand` or `righteous` display, `nunito` text (readable body!), `pacifico` one word. ## 5. Lesson writing

Each era exports a `DesignLesson`:
```ts
{
  principle: 'One sentence a designer would say. Concrete, about THIS layout.',
```
