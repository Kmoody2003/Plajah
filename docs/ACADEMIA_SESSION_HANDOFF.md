## ⚠️ Tailwind v4 "Invalid code point" — ROOT-CAUSED & FIXED (2026-08-24)
The dev server / `vite build` failed with a Tailwind `generate:serve` "Invalid code point" error in `index.css`. **Cause:** Tailwind v4's Oxide scanner scans `.md` files, and an EARLIER version of THIS handoff note pasted the raw scratchpad absolute path; its session-id happened to begin with six hex characters, which the scanner read as a CSS unicode escape and passed to `String.fromCodePoint` — the value exceeds the max code point (0x10FFFF) → invalid. Fixed by removing the raw temp path (verified: dev server serves `index.css` 200, ~1MB, clean). **RULE: never paste raw temp/scratchpad absolute paths — or ANY 6+ hex-digit token — into files Tailwind scans (.md/.mdx/.html/.svg/.ts/.tsx/.css); even documenting the offending hex re-triggers it. Use `<scratchpad>` placeholders.** Not caused by the Academia components (proven by exhaustive bisection).
