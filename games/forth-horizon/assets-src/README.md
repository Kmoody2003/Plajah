# Apex Elohim — Incoming Asset Staging

Drop incoming assets into these subfolders for ingestion into the WebGPU engine:

- `cars/` — Car design sheets (PNG/JPG/WebP) and part-level 3D assemblies (GLB/GLTF/STEP).
- `buildings/` — 3D building models (GLB/GLTF/IFC) for Ironport Downtown & Harborfront.
- `maps/` — Map layouts, elevation/heightmaps, road splines, and coastal reference sheets.
- `textures/` — PBR texture sets (albedo, normal, roughness, metalness, KTX2) for asphalt, sand, concrete, and automotive materials.
- `videos/` — Motion study, visual look-dev, and replay camera reference videos.
